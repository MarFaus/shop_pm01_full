## Дома
1. Скачать проект:
   git clone -b claude/great-wright-2l43x6 https://github.com/MarFaus/shop_pm01_full.git shop
   cd shop
2. Запустить всё:
   docker compose up -d --build
   docker compose ps          (postgres — healthy, app — Up; первый раз ждать ~1 мин)
3. Проверка: http://localhost:8080/products/1 и http://localhost:8080/orders/999999999 (404)
4. Тест (во втором терминале в это время `docker stats`):
   docker compose run --rm k6 run /scripts/load.js
5. Записать в журнал: RPS (http_reqs, /s), p95 (http_req_duration), ошибки (http_req_failed),
   p95 search, p95 order, узкое место (больше всех CPU % в docker stats).
6. Дальше — Лаб 2 (Nginx + 3 воркера).
